Project Description:

This project is a full-stack e-commerce web application built using the MERN stack (MongoDB, Express, React, and Node.js). It allows users to create an account, log in securely, browse products, and add items to their cart. Users can also place orders and view their order history, making the experience similar to a real online shopping platform.

The frontend is developed using React with a clean and responsive UI, while the backend handles authentication, product management, cart functionality, and order processing through REST APIs. The application uses JWT-based authentication to ensure secure user sessions.

The project is fully deployed, with the backend hosted on Render and the frontend on Vercel, making it accessible online. Overall, this project demonstrates practical implementation of full-stack development, API integration, authentication, and deployment workflows.
